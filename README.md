# Reels «Вы когда-нибудь гнались за мерчем?»

## Скачать видео

Откройте папку **delivery** в этом репозитории, выберите MP4 и нажмите **Download raw file** (значок скачивания). Это обычные файлы GitHub, не внутренние ссылки из чата.

- **`delivery/sber_merch_reels_final.mp4` — актуальная версия с русскими субтитрами и присланным фрагментом Kai Angel — «Andy Warhol».**
- `delivery/preview_andy_warhol.mp4` — короткое превью музыкального раскрытия.
- `delivery/sber_merch_reels_captioned_review.mp4` — предыдущая версия с субтитрами без музыки.
- `delivery/sber_merch_reels_clean.mp4` — тот же монтаж без субтитров и музыки.
- `delivery/sber_merch_reels.srt` — отдельные субтитры.

Длительность 25,9 с, 1080×1920, 30 fps, H.264, AAC stereo 48 кГц. Финал — показ серой футболки. Никакие условия розыгрыша не добавлены.

## Текущий статус

Текст диалога подтверждён пользователем 28 октября 2026; тайминги субтитров **приблизительные**, не проверены прослушиванием. Текст хранится в `captions.json`. Для полного диалога сохранён непрерывный первый план. Цифровых приближений и ускорения речи нет.

Музыка: присланный пользователем MP3 Kai Angel — «Andy Warhol», исходный диапазон 00:38.000–00:45.700. Вход в готовом ролике 00:18.200 — раскрытие поисков. Фраза локализована автоматическим распознаванием, не прослушиванием; точность начала фразы не подтверждена на слух. Под музыкой атмосфера поиска приглушена, в конце короткое затухание. Текст песни в субтитры не добавлялся.

Передача видео в этот репозиторий разрешена пользователем. Сам MP3, исходные MOV и ASR-модели не публикуются. Старые синтезированные эскизы исключены из актуальной выдачи.

## Повторить монтаж

Требуются Python 3 и FFmpeg/ffprobe с libx264 и libass. Основной рендер не требует pip-пакетов.

1. Поместить оригиналы `IMG_2976.MOV` и `IMG_2978.MOV` в `assets/`.
2. `python render.py` — собрать чистую версию и исторические музыкальные эскизы.
3. `python finish.py` — сформировать SRT/ASS и версию с субтитрами без музыки.
4. При наличии разрешённого трека: `python finish.py --music assets/Kai_Angel_Andy_warhol.mp3 --music-start 38` (для выбранного пользователем MP3 используется 38).
5. `python validate.py` — полное декодирование, формат, чёрные интервалы и измерение громкости. Измерения файла — поля `input_i`/`input_tp`.

`edit.json`: исходные диапазоны и музыкальный вход. `captions.json`: текст/границы субтитров. `delivery/timeline.json`: исходные и конечные таймкоды. Все скорости 1×. Исходники не изменяются.

Прослушивание в наушниках/на телефоне, полный просмотр в реальном времени и проверка точности синхронизации остаются невыполненными. Техническая проверка их не заменяет.

Техническая проверка последней музыкальной версии: `delivery/final-validation.json`.

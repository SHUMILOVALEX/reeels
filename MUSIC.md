# Музыка

Актуальный выбор пользователя: Kai Angel — «Andy Warhol», фрагмент с указанной пользователем строкой. Этот выбор заменяет прежний поиск и синтезированные эскизы.

Аудиофайл пока отсутствует, точный исходный таймкод не определён. Песня в актуальные MP4 не добавлена. Сторонние записи, обход ограничений стриминга и отдельное распространение песни не используются.

Монтажная точка входа: 00:18.200 готового ролика, спустя 0,6 с после начала выезда из-за стены. Музыкальная секция: 7,7 с, короткое затухание 0,25 с в конце. При предоставлении аудио `finish.py --music ... --music-start ...` заменит звук поиска приглушённой атмосферой с треком. Речь в первой сцене остаётся без музыкальной подложки.
